# 聖地sit

## サイト概要
### サイトテーマ
様々な聖地にまつわる情報をマップ上で検索したり、聖地で自分がした体験に関するレビューを投稿したり出来るコミュニティサイト
​
### テーマを選んだ理由
私は元々歴史の教科がが好きで、暇な時は図書館に行って調べ物をしたり、Youtubeで歴史まとめ系の動画を見たりしていました。その中で私は、普段通っているバイト先が有名な小説の聖地として語られていたことに気付き、この世にはまだまだ知らない聖地があるかもしれないと思い始めました。
しかし、調べるべき知らない事を自分一人の力で調べることは難しく、壁に当たってしまいました。
そこで私は、まだ知らない聖地の情報を知るために他のユーザーの力を借りたいと思い、このテーマを選びました。
またその聖地での楽しみ方にも個性があると思い、それらを知りたいと考えた私はこのテーマをコミュニティサイトとして製作することに決めました。
​
### ターゲットユーザ
・旅が好きで、かつ歴史やデジタルコンテンツが好きな人
・聖地での新しい楽しみ方を知りたいと思っている人

### 主な利用シーン
・自分の身の回りに聖地があるかどうかを知りたいとき
・旅行先の聖地について調べたいとき
・自分が過去に訪れた聖地を、他のユーザーがどう楽しんだかを知りたいとき
